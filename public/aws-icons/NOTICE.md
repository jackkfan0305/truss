# AWS Architecture Icons

## Source

Icons in this directory are from the official [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) package.

- **Package Version**: Icon-package_07312026
- **Release Date**: July 31, 2026
- **Source URL**: https://aws.amazon.com/architecture/icons/
- **Download Date**: October 6, 2026

## Asset Notices

These SVG assets use the official AWS color palette and are simplified representations of the AWS Architecture Icons. Each icon has been reviewed for:

- No embedded scripts or executables
- No external references or data URLs
- No caller-supplied markup
- Safe static local asset usage

Official colors are preserved:
- Service icons: AWS Orange (#FF9900)
- Boundary icons: AWS Blue (#2F7FCC)

## Usage

Icons are referenced by full path in the AWS catalog (`lib/aws-catalog.ts`) and bundled locally. They are never downloaded at runtime or referenced from external sources.
